# KABridge - 한국-아랍 기업 매칭 플랫폼

## 프로젝트 개요
- **이름**: KABridge (Korean-Arab Business Bridge)
- **목표**: 한국과 아랍 지역 기업들 간의 비즈니스 매칭 및 협력 촉진
- **특징**: 채용 플랫폼과 유사한 직관적인 UI/UX로 쉽고 간편한 기업 매칭

## 현재 구현된 기능

### ✅ 완료된 기능
1. **기업 프로필 등록**
   - 기업 기본 정보 (회사명, 국가, 산업 분야, 규모 등)
   - 사업 정보 (제품/서비스, 핵심 기술, 인증 등)
   - 협력 희망 분야 (수출/수입/합작투자/라이센싱 등)

2. **기업 탐색 및 검색**
   - 국가, 산업 분야, 기업 형태별 필터링
   - 키워드 검색 기능
   - 기업 프로필 카드 형태 표시

3. **협력 요청 시스템**
   - 협력 요청 전송 API
   - 받은/보낸 요청 관리
   - 요청 상태 업데이트 (승인/거절/철회)

4. **데이터베이스 구조**
   - 사용자 관리 (users)
   - 기업 프로필 (companies)  
   - 협력 요청 (cooperation_requests)
   - 메시지 시스템 (messages)
   - 즐겨찾기 (favorites)

### 🚧 진행 중인 기능
- 협력 요청 상세보기 및 메신저 기능
- 다국어 지원 (한국어/아랍어/영어)

## 데이터 아키텍처

### 🗄️ 데이터베이스 서비스
- **Cloudflare D1**: SQLite 기반 글로벌 분산 데이터베이스
- **로컬 개발**: `.wrangler/state/v3/d1` 디렉토리의 SQLite 파일

### 📊 주요 데이터 모델
1. **기업 정보**
   - 기본 정보: 회사명, 국가, 산업분야, 규모
   - 비즈니스 정보: 제품/서비스, 기술, 인증
   - 협력 정보: 협력 유형, 목표 지역

2. **협력 요청**
   - 발송자/수신자 정보
   - 협력 유형 및 제목
   - 메시지 및 상태 관리

3. **사용자 시스템**
   - 기업별 계정 관리
   - 언어 및 국가 설정

## 사용자 가이드

### 🏢 기업 등록 방법
1. 메인 페이지에서 "기업 등록하기" 클릭
2. 기업 기본 정보 입력 (회사명, 국가, 산업분야 등)
3. 제품/서비스 및 핵심 기술 정보 입력
4. 협력 희망 분야 선택 (체크박스 다중 선택)
5. 연락처 정보 입력 후 등록 완료

### 🔍 기업 탐색 방법  
1. 상단 네비게이션에서 "기업 탐색" 클릭
2. 검색 필터 설정 (국가, 산업분야, 기업형태, 키워드)
3. 검색 버튼 클릭 또는 엔터키로 검색
4. 결과에서 관심 기업의 "협력 요청" 버튼 클릭

### 📋 협력 요청 관리
1. "협력 요청" 페이지 접속
2. 데모용 기업 선택 (실제 앱에서는 로그인 기업 자동 설정)
3. "받은 요청" / "보낸 요청" 탭 전환
4. 각 요청별 승인/거절/철회 액션 수행

## 기술 스택

### 🛠️ 백엔드
- **Hono**: 경량 웹 프레임워크
- **Cloudflare Workers**: 엣지 컴퓨팅 플랫폼
- **Cloudflare D1**: SQLite 기반 데이터베이스
- **TypeScript**: 타입 안전성

### 🎨 프론트엔드
- **TailwindCSS**: 유틸리티 CSS 프레임워크
- **Font Awesome**: 아이콘 라이브러리
- **Axios**: HTTP 클라이언트
- **Vanilla JavaScript**: 프론트엔드 로직

### 🚀 배포 및 인프라
- **Cloudflare Pages**: 정적 사이트 호스팅
- **Wrangler**: Cloudflare CLI 도구
- **PM2**: 프로세스 매니저 (개발 환경)

## 배포 상태

### ✅ 현재 상태
- **개발 환경**: 활성화됨
- **로컬 데이터베이스**: 설정 완료 (시드 데이터 포함)
- **API 엔드포인트**: 정상 작동
- **웹 인터페이스**: 모든 페이지 접근 가능

### 🔧 개발 환경 실행
```bash
# 프로젝트 빌드
npm run build

# PM2로 개발 서버 시작
pm2 start ecosystem.config.cjs

# 데이터베이스 마이그레이션 (필요시)
npm run db:migrate:local

# 시드 데이터 추가 (필요시)  
npm run db:seed
```
